# France region boundary attribution

Source: gregoiredavid/france-geojson, regions-version-simplifiee.geojson
https://github.com/gregoiredavid/france-geojson
https://raw.githubusercontent.com/gregoiredavid/france-geojson/master/regions-version-simplifiee.geojson

Downloaded 2026-10-16. Original simplified geometry retained; English display names and application IDs added at runtime. Dataset vintage: IGN Admin Express COG / INSEE 2018, according to upstream README. This is a study overlay, not an authoritative current boundary service.

Upstream license statement: Licence Ouverte (Open Licence), via IGN Admin Express conditions.
https://github.com/gregoiredavid/france-geojson#licence
https://github.com/etalab/licence-ouverte

Original data producers: IGN for boundaries; INSEE for geographic names and codes. Conversion and simplification: Grégoire David / france-geojson contributors.

Scope: 13 metropolitan French regions including Corsica; no overseas regions. No regional GeoGuessr claims or imagery are included in this boundary dataset.
